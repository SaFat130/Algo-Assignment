## Project Description
This project is part of the CSE 2422: Algorithms course assignment.

The objective of this project is to implement three classical sorting algorithms and analyze their runtime performance on different input sizes.

The implemented algorithms are:
- Insertion Sort
- Merge Sort
- Quick Sort

Each algorithm is tested with input sizes:
10, 100, 1000, 10000, 100000
